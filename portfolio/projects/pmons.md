# PMons: AI-Powered Monster Battler

## Overview
PMons is a fully-featured Pokémon-inspired monster battler built in Unity where all game content can be procedurally generated by AI. Monster definitions, attacks, items, sprites, and even battle backgrounds are loaded at runtime from a server. An AI can dream up a new creature, generate its artwork, design its abilities with unique combat effects, and players encounter it on their next sync, no code changes needed. The project includes a complete gacha shop, equipment system, daily quests, matchmaking, and a modular battle engine designed from the ground up for extensibility.
- **AI-Generated Content Pipeline**: Everything lives on a server: monster JSON definitions, attack data, item stats, character sprites, and battle backgrounds. An AI workflow generates all of this, artwork included, and pushes updates that players receive instantly.
- **Full Mobile Game Loop**: Shop with gacha banners, equipment crafting, egg hatching, daily/random quests with scaling rewards, resource economy (coins, gems, food), team management, and storage.
